## Apa Itu Cron Jobs?

Cron itu **task scheduler** di Unix/Linux. Lo bisa jadwalin command atau script jalan secara otomatis di waktu tertentu.

```
┌─────────────────────────────────────────────────────────────┐
│                    Cron Jobs: Scheduled Automation              │
│                                                              │
│   Lo: "Hai cron, jalankan script cleanup.sh setiap jam 2 pagi" │
│   Cron: "Siap boss!"                                          │
│   Cron: *jam 2 pagi* → Otomatis jalan script                  │
│   Cron: *jam 2 pagi berikutnya* → Jalan lagi                    │
│   Cron: *jam 2 pagi lagi* → Jalan lagi...                    │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### Cron Syntax

Ini bagian penting | lo harus ngerti syntax cron.

```
┌─────────────────────────────────────────────────────────────┐
│                    Cron Syntax                                  │
│                                                              │
│   * * * * * command                                          │
│   │ │ │ │ │                                                  │
│   │ │ │ │ └── Day of week (0-7, Sunday=0)                   │
│   │ │ │ └──── Month (1-12)                                  │
│   │ │ └────── Day of month (1-31)                           │
│   │ └──────── Hour (0-23)                                     │
│   └───────── Minute (0-59)                                    │
│                                                              │
│   Special characters:                                         │
│   * = any value                                              │
│   , = list separator (1,3,5)                                │
│   - = range (1-5)                                           │
│   / = step (*/15 = every 15 minutes)                       │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### Common Examples

```
┌─────────────────────────────────────────────────────────────┐
│                    Cron Examples                                │
│                                                              │
│   * * * * *          Every minute                             │
│   */5 * * * *       Every 5 minutes                          │
│   0 * * * *          Every hour                               │
│   0 0 * * *          Every midnight                           │
│   0 2 * * *          Every day at 2 AM                       │
│   0 2 * * 0          Every Sunday at 2 AM                     │
│   0 2 1 * *          First day of month at 2 AM               │

│   0 2 * * 1-5       Weekdays at 2 AM (Mon-Fri)              │

└─────────────────────────────────────────────────────────────┘
```

## Setup Cron Jobs di Level OS (Crontab)

Oke, sekarang praktiknya. Lo bakal setup cron job di VPS dengan crontab.

### Step 1: SSH ke VPS

```bash
ssh user@your-server.com
```

### Step 2: Edit Crontab

```bash
# Buka crontab editor
crontab -e

# Pertama kali? Pilih editor (nano recommended)
# Select an editor.  To change later, run 'select-editor'.
# 1. /bin/nano
# 2. /usr/bin/vim.basic
# 3. /usr/bin/vim.tiny
# Choose 1-3 [1]: 1
```

### Step 3: Tambah Cron Job

Tambahkan ini di crontab editor:

```bash
# ═══════════════════════════════════════════════════════════
# Database Maintenance Jobs
# ═══════════════════════════════════════════════════════════

# Delete expired sessions every day at 2 AM
0 2 * * * /usr/bin/node /var/www/myapp/scripts/cleanup-sessions.js >> /var/log/cron/cleanup-sessions.log 2>&1

# Delete abandoned carts every Monday at 3 AM
0 3 * * 1 /usr/bin/node /var/www/myapp/scripts/cleanup-carts.js >> /var/log/cron/cleanup-carts.log 2>&1

# Generate daily reports at 6 AM
0 6 * * * /usr/bin/node /var/www/myapp/scripts/generate-reports.js >> /var/log/cron/generate-reports.log 2>&1

# Backup database every day at 1 AM
0 1 * * * /usr/bin/pg_dump -U postgres myapp | gzip > /backups/myapp-$(date +\%Y\%m\%d).sql.gz

# ═══════════════════════════════════════════════════════════
# Log Management
# ═══════════════════════════════════════════════════════════

# Rotate logs every Sunday at midnight
0 0 * * 0 /usr/sbin/logrotate -f /etc/logrotate.d/myapp
```

### Step 4: Save dan Exit

```
Nano: Ctrl + O → Enter → Ctrl + X
Vim: :wq → Enter
```

### Step 5: Verify Cron Jobs

```bash
# List semua cron jobs
crontab -l

# Output:
# # DO NOT EDIT THIS FILE - edit the master and reinstall.
# # (cron version -- $Id$)
#
# Database Maintenance Jobs
# Delete expired sessions every day at 2 AM
# 0 2 * * * /usr/bin/node /var/www/myapp/scripts/cleanup-sessions.js >> /var/log/cron/cleanup-sessions.log 2>&1
# ...
```

### Step 6: Log Rotation

Buat direktori log dan configure:

```bash
# Buat direktori log
sudo mkdir -p /var/log/cron
sudo chown -R $USER:$USER /var/log/cron

# Create logrotate config
sudo nano /etc/logrotate.d/myapp-cron
```

```bash
# /etc/logrotate.d/myapp-cron
/var/log/cron/*.log {
    daily
    rotate 7
    compress
    delaycompress
    missingok
    notifempty
    create 0640 root root
}
```

## Script Examples untuk Cron

Sekarang gue bakal kasih contoh script yang bisa lo jalanin dari cron.

### 1. Cleanup Expired Sessions

```javascript
// scripts/cleanup-sessions.js
const { Pool } = require('pg');
require('dotenv').config();

const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
});

async function cleanupExpiredSessions() {
  console.log('Starting session cleanup...');
  console.log(`Timestamp: ${new Date().toISOString()}`);

  try {
    const result = await pool.query(`
      DELETE FROM sessions
      WHERE expires_at < NOW()
      RETURNING id
    `);

    console.log(`Deleted ${result.rowCount} expired sessions`);

    // Get remaining count
    const remaining = await pool.query('SELECT COUNT(*) FROM sessions');
    console.log(`Remaining sessions: ${remaining.rows[0].count}`);

  } catch (error) {
    console.error('Error during cleanup:', error);
    process.exit(1);
  } finally {
    await pool.end();
  }

  console.log('Session cleanup completed');
}

cleanupExpiredSessions();
```

### 2. Cleanup Abandoned Carts

```javascript
// scripts/cleanup-carts.js
const { Pool } = require('pg');

const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
});

async function cleanupAbandonedCarts() {
  console.log('Starting abandoned cart cleanup...');

  const ABANDONED_DAYS = 30; // Carts older than 30 days

  try {
    // Delete abandoned cart items first (foreign key constraint)
    const deleteItemsResult = await pool.query(`
      DELETE FROM cart_items
      WHERE cart_id IN (
        SELECT id FROM carts
        WHERE updated_at < NOW() - INTERVAL '${ABANDONED_DAYS} days'
        AND status = 'active'
      )
      RETURNING id
    `);

    console.log(`Deleted ${deleteItemsResult.rowCount} abandoned cart items`);

    // Delete abandoned carts
    const deleteCartsResult = await pool.query(`
      DELETE FROM carts
      WHERE updated_at < NOW() - INTERVAL '${ABANDONED_DAYS} days'
      AND status = 'active'
      RETURNING id
    `);

    console.log(`Deleted ${deleteCartsResult.rowCount} abandoned carts`);

    // Cleanup orphaned products (just for cleanup)
    const orphanedProducts = await pool.query(`
      DELETE FROM products
      WHERE stock = 0
      AND created_at < NOW() - INTERVAL '90 days'
      RETURNING id
    `);

    console.log(`Deleted ${orphanedProducts.rowCount} orphaned products`);

    const stats = await pool.query(`
      SELECT
        (SELECT COUNT(*) FROM carts) as total_carts,
        (SELECT COUNT(*) FROM products WHERE stock = 0) as out_of_stock_products
    `);

    console.log('Current stats:', stats.rows[0]);

  } catch (error) {
    console.error('Error:', error);
    process.exit(1);
  } finally {
    await pool.end();
  }

  console.log('Abandoned cart cleanup completed');
}

cleanupAbandonedCarts();
```

### 3. Generate Daily Report

```javascript
// scripts/generate-reports.js
const { Pool } = require('pg');
const fs = require('fs').promises;

const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
});

async function generateDailyReport() {
  console.log('Generating daily report...');

  const today = new Date().toISOString().split('T')[0];
  const reportPath = `/var/log/reports/daily-${today}.json`;

  try {
    // Ensure directory exists
    await fs.mkdir('/var/log/reports', { recursive: true });

    // Get metrics
    const [
      usersCount,
      ordersCount,
      revenueResult,
      topProducts,
    ] = await Promise.all([
      pool.query('SELECT COUNT(*) FROM users WHERE created_at::date = CURRENT_DATE'),
      pool.query('SELECT COUNT(*) FROM orders WHERE created_at::date = CURRENT_DATE'),
      pool.query(`
        SELECT SUM(total) as revenue
        FROM orders
        WHERE created_at::date = CURRENT_DATE
        AND status = 'completed'
      `),
      pool.query(`
        SELECT p.name, SUM(oi.quantity) as total_sold
        FROM order_items oi
        JOIN products p ON oi.product_id = p.id
        JOIN orders o ON oi.order_id = o.id
        WHERE o.created_at::date = CURRENT_DATE
        AND o.status = 'completed'
        GROUP BY p.id, p.name
        ORDER BY total_sold DESC
        LIMIT 5
      `),
    ]);

    const report = {
      generatedAt: new Date().toISOString(),
      date: today,
      metrics: {
        newUsers: parseInt(usersCount.rows[0].count),
        newOrders: parseInt(ordersCount.rows[0].count),
        dailyRevenue: parseFloat(revenueResult.rows[0].revenue) || 0,
      },
      topProducts: topProducts.rows,
    };

    // Save to file
    await fs.writeFile(reportPath, JSON.stringify(report, null, 2));

    // Also save to database for historical tracking
    await pool.query(`
      INSERT INTO daily_reports (date, metrics, top_products)
      VALUES ($1, $2, $3)
      ON CONFLICT (date) DO UPDATE SET
        metrics = $2,
        top_products = $3,
        updated_at = NOW()
    `, [today, JSON.stringify(report.metrics), JSON.stringify(report.topProducts)]);

    console.log(`Report saved to ${reportPath}`);
    console.log('Report:', JSON.stringify(report.metrics, null, 2));

  } catch (error) {
    console.error('Error generating report:', error);
    process.exit(1);
  } finally {
    await pool.end();
  }

  console.log('Daily report generation completed');
}

generateDailyReport();
```

## Setup Cron Jobs di Level Aplikasi (node-cron)

Sekarang alternatif | setup cron jobs langsung di aplikasi dengan node-cron.

Ini lebih portable | lo nggak perlu setup crontab di setiap server. Cron jobs jalan pas aplikasi jalan.

### Install Dependencies

```bash
npm install node-cron
npm install -D @types/node-cron
```

### Basic Setup

```javascript
// src/scheduler.js
const cron = require('node-cron');

// Import tasks
const { cleanupExpiredSessions } = require('./tasks/session-cleanup');
const { cleanupAbandonedCarts } = require('./tasks/cart-cleanup');
const { generateDailyReport } = require('./tasks/generate-report');
const { sendDailySummary } = require('./tasks/send-summary');

function setupScheduler() {
  console.log('Setting up scheduled tasks...');

  // Cleanup expired sessions - every day at 2 AM
  cron.schedule('0 2 * * *', async () => {
    console.log('Running session cleanup task...');
    try {
      await cleanupExpiredSessions();
    } catch (error) {
      console.error('Session cleanup failed:', error);
    }
  }, {
    timezone: 'Asia/Jakarta'
  });

  // Cleanup abandoned carts - every Monday at 3 AM
  cron.schedule('0 3 * * 1', async () => {
    console.log('Running abandoned cart cleanup...');
    try {
      await cleanupAbandonedCarts();
    } catch (error) {
      console.error('Cart cleanup failed:', error);
    }
  }, {
    timezone: 'Asia/Jakarta'
  });

  // Generate daily report - every day at 6 AM
  cron.schedule('0 6 * * *', async () => {
    console.log('Generating daily report...');
    try {
      await generateDailyReport();
    } catch (error) {
      console.error('Report generation failed:', error);
    }
  }, {
    timezone: 'Asia/Jakarta'
  });

  // Send daily summary - every day at 7 AM
  cron.schedule('0 7 * * *', async () => {
    console.log('Sending daily summary...');
    try {
      await sendDailySummary();
    } catch (error) {
      console.error('Summary sending failed:', error);
    }
  }, {
    timezone: 'Asia/Jakarta'
  });

  console.log('Scheduled tasks configured');
}

module.exports = { setupScheduler };
```

### Advanced: node-cron with Options

```javascript
// Scheduled task dengan retry logic
cron.schedule('0 2 * * *', async () => {
  const maxRetries = 3;
  let attempt = 0;

  while (attempt < maxRetries) {
    try {
      console.log(`Cleanup attempt ${attempt + 1}/${maxRetries}`);
      await cleanupExpiredSessions();
      console.log('Cleanup completed successfully');
      break; // Success, exit loop
    } catch (error) {
      attempt++;
      console.error(`Attempt ${attempt} failed:`, error.message);

      if (attempt >= maxRetries) {
        console.error('All retry attempts failed');
        // Send alert notification
        await sendAlert('Cleanup job failed after 3 attempts');
      } else {
        // Wait before retry (exponential backoff)
        const delay = Math.pow(2, attempt) * 1000;
        await new Promise(resolve => setTimeout(resolve, delay));
      }
    }
  }
}, {
  timezone: 'Asia/Jakarta',
  scheduled: true,
});
```

## Best Practices

### 1. Timezone Management

```javascript
// ❌ BAD: Assume server timezone
cron.schedule('0 2 * * *', () => {
  // Runs at 2 AM server time (could be UTC, PST, etc)
});

// ✅ GOOD: Explicit timezone
cron.schedule('0 2 * * *', () => {
  // Runs at 2 AM Jakarta time (Asia/Jakarta)
}, {
  timezone: 'Asia/Jakarta'
});
```

### 2. Logging

```javascript
// Always log start and end
async function scheduledTask() {
  const startTime = Date.now();
  console.log(`[${new Date().toISOString()}] Task started`);

  try {
    await doSomething();
    console.log(`[${new Date().toISOString()}] Task completed successfully`);
  } catch (error) {
    console.error(`[${new Date().toISOString()}] Task failed:`, error);
  }

  const duration = Date.now() - startTime;
  console.log(`Task took ${duration}ms`);
}
```

### 3. Error Handling

```javascript
// Wrap everything in try-catch
cron.schedule('0 2 * * *', async () => {
  try {
    // All logic here
  } catch (error) {
    // Log error
    console.error('Cron job failed:', error);

    // Send notification
    await sendAlert(`Cron job failed: ${error.message}`);

    // Exit with error code (for crontab)
    process.exit(1);
  }
});
```

### 4. Prevent Overlap

Kalo task jalan lebih lama dari interval, lo nggak mau task kedua mulai sebelum task pertama selesai.

```javascript
// Lock file approach
const fs = require('fs');

async function scheduledTask() {
  const lockFile = '/tmp/cleanup.lock';

  // Check if already running
  if (fs.existsSync(lockFile)) {
    const stats = fs.statSync(lockFile);
    const age = Date.now() - stats.mtime.getTime();

    // If lock is less than 1 hour old, skip
    if (age < 60 * 60 * 1000) {
      console.log('Previous task still running, skipping...');
      return;
    }

    console.log('Stale lock file found, removing...');
    fs.unlinkSync(lockFile);
  }

  // Create lock file
  fs.writeFileSync(lockFile, process.pid.toString());

  try {
    await doCleanup();
  } finally {
    // Remove lock file
    fs.unlinkSync(lockFile);
  }
}
```

## Common Cron Mistakes

### 1. Missing Environment Variables

```bash
# ❌ BAD: Script fails because .env not loaded
0 2 * * * node /var/www/app/scripts/cleanup.js

# ✅ GOOD: Load environment first
0 2 * * * cd /var/www/app && /usr/bin/node -r dotenv/config scripts/cleanup.js

# ✅ Or source .env first
0 2 * * * source /var/www/app/.env && node /var/www/app/scripts/cleanup.js
```

### 2. Wrong PATH

```bash
# ❌ BAD: Command not found
0 2 * * * node scripts/cleanup.js  # Relative path
0 2 * * * npm run cleanup          # npm might not be in PATH

# ✅ GOOD: Absolute paths
0 2 * * * /usr/bin/node /var/www/app/scripts/cleanup.js
0 2 * * * cd /var/www/app && /usr/local/bin/npm run cleanup
```

### 3. No Logging

```bash
# ❌ BAD: No idea what happened
0 2 * * * /usr/bin/node /var/www/app/scripts/cleanup.js

# ✅ GOOD: Log everything
0 2 * * * /usr/bin/node /var/www/app/scripts/cleanup.js >> /var/log/cron/cleanup.log 2>&1
```

### 4. Not Handling Failures

```bash
# ❌ BAD: Silent failures
0 2 * * * /usr/bin/node /var/www/app/scripts/cleanup.js

# ✅ GOOD: Alert on failure
0 2 * * * /usr/bin/node /var/www/app/scripts/cleanup.js || /usr/bin/mail -s "Cleanup Failed" admin@example.com
```
