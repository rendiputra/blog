## Kenapa Testing Manual Itu Masalah?

Oke, pertama lo harus ngerti kenapa testing manual itu problematic.

### Testing Manual = Boring & Time-Consuming

```
Manual testing workflow:
| 1. Buka Postman / Insomnia
| 2. Setup environment
| 3. Ngetik endpoint URL
| 4. Ngetik headers
| 5. Ngetik body
| 6. Klik Send
| 7. Liat response
| 8. Repeat 100 kali untuk semua endpoints

Time per test: ~2 menit
Total endpoints: 50
Total time: 100 menit = 1.7 jam!

Setiap kali ada perubahan? Ulang dari awal.
```

50 endpoints × 2 menit = 1.7 jam. Itu cuma buat ngetes sekali. Kalo ada bug? Ulang lagi.

### Human Error

```
Lo ngetes endpoint /api/users/123:
| Expected: 200 OK dengan user object
| Lo liat response:
| {
|   "id": 123,
|   "name": "Andi",
|   "email": "andi@example.com"
| }

Lo: "Yep, looks good. ✓"

Tapi tau nggak? Response sebenarnya:
| {
|   "id": 123,
|   "name": "Andi",
|   "email": "andi@example.com",
|   "password_hash": "$2b$10$xyz..."  ← INI SEHARUSNYA GAK ADA!
| }

Lo nggak perhatiin password_hash karena lo fokus ke field yang "bener".

Human eyes = unreliable.
```

Lo bisa aja lewatin bug karena kelelahan atau salah fokus.

### Regression Bug

Ini yang paling bahaya. Lo nambahin fitur baru. Features lama broken.

```
Timeline:

Monday | Lo bikin API orders | All tests pass ✓
Tuesday | Lo bikin API payments | All tests pass ✓
Wednesday | Lo bikin endpoint /api/checkout | All tests pass ✓
Thursday | Lo refactor /api/orders buat optimize query |
          Lo deploy ke production
Friday | User checkout error! /api/orders return null

Why?
Lo nggak ngetes /api/orders setelah refactor.
Lo cuma ngetes /api/checkout yang baru.
Regression bug.
```

**Lo pernah ngalamin ini?** Probably yes.

## Solusinya: Automated Testing

Automated testing itu script yang otomatisasi semua proses testing.

```
Manual Testing:
| Buka Postman → Klik → Liat Response → Repeat
| 2 menit per endpoint × 50 = 1.7 jam

Automated Testing:
| jalankan script → otomatis ngetes semua → Done
| 30 detik untuk 50 endpoints
| Every time, consistently
```

**Benefits:**
- Fast | detik bukan menit
- Consistent | selalu sama hasilnya
- Reliable | nggak ada human error
- Regression | automatically detect broken features
- Documentation | test = documentation

## Jenis-Jenis Test

Ada banyak jenis test, tapi 2 yang paling penting:

### 1. Unit Test

Unit test ngetes **bagian terkecil** dari code secara isolated.

```
Unit test examples:
| Function: calculateTotal(items)
| | Input: [{price: 100, qty: 2}, {price: 50, qty: 1}]
| | Expected: 250
| | Test: calculateTotal([...]) should return 250

Unit test:
| Test satu function
| Mock dependencies
| Fast execution
| Isolate bugs
```

### 2. Integration Test

Integration test ngetes **bagaimana bagian-bagian bekerja sama**.

```
Integration test examples:
| Endpoint: POST /api/users
| | HTTP request ke Express server
| | Express → Controller → Service → Database
| | Verify response dan database state
| | Test: POST /api/users should create user in DB

Integration test:
| Test flow lengkap
| Real database
| Real HTTP requests
| Verify end-to-end behavior
```

**Kapan pake yang mana?**

```
Pake Unit Test kalo:
| Lo ngetes business logic
| Function yang complex
| Lo nggak mau connect ke database
| Lo mau fast feedback

Pake Integration Test kalo:
| Lo ngetes API endpoints
| Lo mau verify HTTP response
| Lo mau verify database state
| Lo mau test flow yang realistic
```

## Unit Test Example

Oke, gue mulai dengan Unit Test untuk business logic.

### Contoh Function yang Mau Dites

```javascript
// src/services/order.service.js

/**
 * Calculate order total
 * @param {Array} items - Array of order items
 * @returns {number} Total price
 */
function calculateTotal(items) {
  if (!items || !Array.isArray(items)) {
    throw new Error('Items must be an array');
  }

  return items.reduce((total, item) => {
    if (!item.price || !item.quantity) {
      throw new Error('Each item must have price and quantity');
    }
    return total + (item.price * item.quantity);
  }, 0);
}

/**
 * Apply discount to total
 * @param {number} total - Original total
 * @param {string} discountCode - Discount code
 * @returns {number} Final total after discount
 */
function applyDiscount(total, discountCode) {
  const discounts = {
    'SAVE10': 0.10,    // 10% off
    'SAVE20': 0.20,    // 20% off
    'SAVE30': 0.30,    // 30% off
    'FLAT50': 0,       // Rp 50.000 off (handled differently)
  };

  const discountRate = discounts[discountCode] || 0;
  return Math.round(total * (1 - discountRate));
}

module.exports = { calculateTotal, applyDiscount };
```

### Unit Test untuk Function Tersebut

```javascript
// src/services/__tests__/order.service.test.js

const { calculateTotal, applyDiscount } = require('../order.service');

describe('Order Service', () => {
  describe('calculateTotal', () => {
    test('should calculate total correctly', () => {
      const items = [
        { price: 100000, quantity: 2 },
        { price: 50000, quantity: 1 }
      ];

      const total = calculateTotal(items);

      expect(total).toBe(250000); // (100000 * 2) + (50000 * 1) = 250000
    });

    test('should return 0 for empty array', () => {
      const items = [];

      const total = calculateTotal(items);

      expect(total).toBe(0);
    });

    test('should throw error if items is not an array', () => {
      expect(() => calculateTotal(null)).toThrow('Items must be an array');
      expect(() => calculateTotal('string')).toThrow('Items must be an array');
      expect(() => calculateTotal(123)).toThrow('Items must be an array');
    });

    test('should throw error if item missing price or quantity', () => {
      const items = [{ price: 100000 }]; // missing quantity

      expect(() => calculateTotal(items)).toThrow(
        'Each item must have price and quantity'
      );
    });
  });

  describe('applyDiscount', () => {
    test('should apply 10% discount with SAVE10 code', () => {
      const total = 100000;
      const final = applyDiscount(total, 'SAVE10');

      expect(final).toBe(90000); // 10% off
    });

    test('should apply 20% discount with SAVE20 code', () => {
      const total = 100000;
      const final = applyDiscount(total, 'SAVE20');

      expect(final).toBe(80000); // 20% off
    });

    test('should return original total for invalid code', () => {
      const total = 100000;
      const final = applyDiscount(total, 'INVALID');

      expect(final).toBe(100000);
    });

    test('should return original total for empty code', () => {
      const total = 100000;
      const final = applyDiscount(total, '');

      expect(final).toBe(100000);
    });
  });
});
```

## Integration Test Example

Sekarang Integration Test untuk API endpoints.

### Setup Express Server untuk Testing

```javascript
// src/app.js
const express = require('express');
const app = express();

app.use(express.json());

// Mock routes (simplified)
const users = [
  { id: 1, name: 'Andi', email: 'andi@example.com' },
  { id: 2, name: 'Budi', email: 'budi@example.com' }
];

app.get('/api/users', (req, res) => {
  res.json({ data: users });
});

app.get('/api/users/:id', (req, res) => {
  const user = users.find(u => u.id === parseInt(req.params.id));
  if (!user) {
    return res.status(404).json({ error: 'User not found' });
  }
  res.json({ data: user });
});

app.post('/api/users', (req, res) => {
  const { name, email } = req.body;

  if (!name || !email) {
    return res.status(400).json({ error: 'Name and email are required' });
  }

  const existingUser = users.find(u => u.email === email);
  if (existingUser) {
    return res.status(409).json({ error: 'Email already exists' });
  }

  const newUser = {
    id: users.length + 1,
    name,
    email
  };
  users.push(newUser);

  res.status(201).json({ data: newUser });
});

app.delete('/api/users/:id', (req, res) => {
  const index = users.findIndex(u => u.id === parseInt(req.params.id));
  if (index === -1) {
    return res.status(404).json({ error: 'User not found' });
  }

  users.splice(index, 1);
  res.json({ message: 'User deleted successfully' });
});

module.exports = app;
```

## TDD: Test-Driven Development

Ini philosophy testing yang powerful | **write tests BEFORE code**.

### Red-Green-Refactor Cycle

```
1. RED | Tulis test dulu, jalankan, harus FAIL
2. GREEN | Tulis code minimun buat test PASS
3. REFACTOR | Improve code tanpa ubah behavior
```

### TDD Example

```javascript
// Step 1: RED | Tulis test dulu
describe('formatCurrency', () => {
  test('should format number to Indonesian Rupiah', () => {
    expect(formatCurrency(100000)).toBe('Rp 100.000');
    expect(formatCurrency(1500000)).toBe('Rp 1.500.000');
    expect(formatCurrency(500)).toBe('Rp 500');
  });
});

// Run test | FAIL | Function doesn't exist yet

// Step 2: GREEN | Write minimal code
function formatCurrency(amount) {
  return 'Rp ' + amount.toLocaleString('id-ID');
}

// Run test | PASS!

// Step 3: REFACTOR | Improve if needed
// Code udah clean, test udah pass, done!
```

**Benefits of TDD:**
- Forces lo think about requirements before coding
- Tests document expected behavior
- Code always has test coverage
- Refactoring with confidence

## Testing Best Practices

### 1. Test One Thing at a Time

```javascript
// ❌ BAD | Test multiple things
test('should create user and return 201', async () => {
  // Create user
  // Verify response
  // Verify database
  // Verify email sent (async side effect)
  // This is too much for one test!
});

// ✅ GOOD | One assertion per test
test('should return 201 for valid request', async () => {
  // Just test response status
});

test('should create user in database', async () => {
  // Just test database state
});
```

### 2. Use Descriptive Test Names

```javascript
// ❌ BAD | Vague names
test('create user', () => { ... });
test('error', () => { ... });
test('test', () => { ... });

// ✅ GOOD | Descriptive names
test('should return 201 when creating user with valid data', () => { ... });
test('should return 400 when name is missing', () => { ... });
test('should return 409 when email already exists', () => { ... });
```

### 3. Arrange-Act-Assert Pattern

```javascript
test('should calculate discount correctly', async () => {
  // Arrange
  const items = [
    { price: 100000, quantity: 2 },
    { price: 50000, quantity: 1 }
  ];
  const discountCode = 'SAVE10';

  // Act
  const result = applyDiscount(calculateTotal(items), discountCode);

  // Assert
  expect(result).toBe(225000); // 250000 - 10% = 225000
});
```

### 4. Keep Tests Fast

```javascript
// ❌ BAD | Slow test (3 seconds)
test('should handle slow API', async () => {
  const response = await fetch('https://slow-api.example.com/data');
  await new Promise(resolve => setTimeout(resolve, 3000)); // Sleep 3s
  expect(response.ok).toBe(true);
});

// ✅ GOOD | Fast test (use mocks)
test('should handle slow API', async () => {
  // Mock the slow API
  jest.mock('node-fetch', () => jest.fn(() => Promise.resolve({ ok: true })));

  const response = await fetchData();
  expect(response.ok).toBe(true);
});
```
