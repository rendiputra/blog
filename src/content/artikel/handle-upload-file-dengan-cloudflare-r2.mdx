## Kenapa Nggak Simpan File di VPS?

Oke, gue kasih alasan concrete kenapa menyimpan file di VPS itu ide yang kurang bagus:

### 1. Storage Limited dan Mahal

```
VPS Storage Reality:
| $6/month VPS | 25-50GB storage
| $20/month VPS | 100-200GB storage
| $50/month VPS | 500GB storage

Upload 100MB file x 1000 users | 100GB terpakai
Upload profile pictures x 10,000 users | 50GB terpakai
Backup? | 20GB terpakai
```

Storage VPS itu expensive. Per GB-nya lebih mahal daripada dedicated object storage.

### 2. Backup jadi Nightmare

```bash
# Backup VPS with file uploads included
du -sh /var/www/uploads
# Output: 45G used

# Time to backup 45GB?
tar -czf backup-$(date +%Y%m%d).tar.gz /var/www/uploads
# Estimated time: 15-30 minutes
# Bandwidth: 45GB outbound

# Every day? That's expensive.
```

Lo harus backup everything | termasuk user-generated content. Bandwidth dan storage cost membengkak.

### 3. Single Point of Failure

```
Scenario:
| VPS crashes
| Data center goes down
| Disk failure

Result:
| All user files gone
| No redundancy
| User trust destroyed
```

Object storage seperti R2 punya built-in redundancy. File lo di-replicate otomatis. VPS storage? Lo harus setup RAID, backup strategy, dan semua sendiri.

### 4. Performance Impact

```nginx
# Serving files from VPS Nginx
location /uploads/ {
    alias /var/www/uploads/;
    sendfile on;
    tcp_nopush on;
}

# Kalau 1000 users simultaneously download files?
# VPS CPU dan bandwidth bottleneck
# User experience: slow loading
```

Serving static files dari VPS competes dengan application code untuk resource. Object storage with CDN? File served dari edge location terdekat dengan user.

## Solusinya: Cloudflare R2

Oke, sekarang ngomongin R2. Apa sih sebenarnya Cloudflare R2?

### Apa Itu R2?

R2 adalah object storage dari Cloudflare yang **S3-compatible**. Ini artinya lo bisa pakai semua tools dan SDK yang sudah ada untuk S3, tapi dengan pricing model yang lebih baik.

```
R2 vs AWS S3 vs Google Cloud Storage:

| Provider | Storage (per GB) | Class A Ops | Class B Ops | Egress |
|----------|------------------|-------------|-------------|--------|
| AWS S3   | $0.023           | $0.005/1k   | $0.0004/1k | $0.09/GB |
| GCS      | $0.020           | $0.05/1k    | $0.004/1k   | $0.12/GB |
| Cloudflare R2 | $0.015       | $0.00       | $0.00       | $0.00 |

Class A = Write, copy, list (expensive)
Class B = Read, download (cheaper)

R2 egress itu GRATIS. Unlimited bandwidth keluar.
```

**Game changer**: egress gratis. Lo nggak akan di-surprise sama billing karena user lu download banyak file.

### Kenapa R2, Bukan S3 Langsung?

```
Pro R2:
| Egress gratis (S3: $0.09/GB)
| S3-compatible (existing code works)
| Integrated dengan Cloudflare (Workers, Images, Stream)
| Cache with Workers (zero cost caching)
| Simpler pricing

Pro S3:
| More mature ecosystem
| More regions available
| Advanced features (lifecycle policies, intelligent tiering)
| Enterprise features

For side projects and startups: R2 wins on cost.
```

## Setup R2 Step by Step

Oke, sekarang gimana cara setup-nya?

### Step 1: Buat R2 Bucket

1. Login ke [Cloudflare Dashboard](https://dash.cloudflare.com)
2. Pilih menu **R2** di sidebar
3. Klik **Create bucket**
4. Masukin nama bucket | contoh: `my-app-uploads`
5. Pilih region (biarkan auto if not sure)

```
Bucket created successfully!
Bucket Name: my-app-uploads
Bucket ID: abc123def456
Date Created: 2024-01-15
```

### Step 2: Generate API Token

1. Di R2 dashboard, klik **Manage API Token**
2. Klik **Create API Token**
3. Pilih template | **Edit Cloudflare R2**
4. Set specific bucket permissions:
   - Account: Read Permission Tokens
   - Bucket: `my-app-uploads` | Read + Write
5. Klik **Create**
6. **IMPORTANT**: Copy dan simpan `Account ID`, `Access Key ID`, dan `Secret Access Key`

```bash
# Simpan credentials di .env
R2_ACCOUNT_ID=abc123def456
R2_ACCESS_KEY_ID=xxxxx
R2_SECRET_ACCESS_KEY=yyyyy
R2_BUCKET_NAME=my-app-uploads
R2_PUBLIC_URL=https://pub-xxx.r2.dev  # nanti kita setup custom domain
```

### Step 3: Setup Custom Domain (Optional tapi recommended)

Ini biar file lo accessible lewat domain lu sendiri.

1. Di R2 dashboard, pilih bucket `my-app-uploads`
2. Klik **Settings**
3. Scroll ke **Custom Domain**
4. Add domain | contoh: `assets.mydomain.com`
5. Point CNAME ke `pub-xxx.r2.dev`

```
Custom Domain Setup:
| Subdomain: assets.mydomain.com
| Target: pub-xxx.r2.dev
| SSL/TLS: Flexible (R2 handles it)

Now: https://assets.mydomain.com/file.jpg
Instead of: https://pub-xxx.r2.dev/my-app-uploads/file.jpg
```

Lo juga bisa setup Workers untuk serve files dengan caching:

```javascript
// workers/serve-r2.js
export default {
  async fetch(request, env) {
    const url = new URL(request.url);
    const key = url.pathname.slice(1); // Remove leading slash

    const object = await env.MY_BUCKET.get(key);

    if (object === null) {
      return new Response('Not Found', { status: 404 });
    }

    const headers = new Headers();
    headers.set('Content-Type', object.httpMetadata.contentType || 'application/octet-stream');
    headers.set('Cache-Control', 'public, max-age=86400'); // Cache 1 day

    return new Response(object.body, {
      headers,
    });
  },
};
```

## Integrasi dengan Aplikasi

Sekarang bagian yang seru | gimana cara upload ke R2 dari aplikasi lu.

### Node.js (AWS SDK v3)

```bash
npm install @aws-sdk/client-s3 @aws-sdk/s3-request-presigner
```

```javascript
// r2-upload.js
const { S3Client, PutObjectCommand, GetObjectCommand } = require('@aws-sdk/client-s3');
const { getSignedUrl } = require('@aws-sdk/s3-request-presigner');

// Initialize R2 client
const r2 = new S3Client({
  region: 'auto',
  endpoint: `https://${process.env.R2_ACCOUNT_ID}.r2.cloudflarestorage.com`,
  credentials: {
    accessKeyId: process.env.R2_ACCESS_KEY_ID,
    secretAccessKey: process.env.R2_SECRET_ACCESS_KEY,
  },
});

async function uploadFile(fileBuffer, fileName, contentType) {
  const command = new PutObjectCommand({
    Bucket: process.env.R2_BUCKET_NAME,
    Key: fileName,
    Body: fileBuffer,
    ContentType: contentType,
  });

  const result = await r2.send(command);
  console.log('File uploaded:', result);

  // Generate presigned URL for public access
  const getCommand = new GetObjectCommand({
    Bucket: process.env.R2_BUCKET_NAME,
    Key: fileName,
  });

  const signedUrl = await getSignedUrl(r2, getCommand, { expiresIn: 3600 });
  return signedUrl;
}

// Usage in Express route
app.post('/upload', upload.single('file'), async (req, res) => {
  try {
    const file = req.file;
    const fileName = `uploads/${Date.now()}-${file.originalname}`;

    const url = await uploadFile(
      file.buffer,
      fileName,
      file.mimetype
    );

    res.json({ success: true, url });
  } catch (error) {
    console.error('Upload error:', error);
    res.status(500).json({ error: 'Upload failed' });
  }
});
```

```php
// app/Http/Controllers/UploadController.php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;
use Illuminate\Support\Facades\Storage;

class UploadController extends Controller
{
    public function upload(Request $request)
    {
        $request->validate([
            'file' => 'required|file|max:10240', // 10MB max
        ]);

        $file = $request->file('file');
        $filename = 'uploads/' . time() . '-' . $file->getClientOriginalName();

        // Upload ke R2
        $path = Storage::disk('r2')->put($filename, file_get_contents($file));

        if ($path) {
            // Generate public URL
            $url = Storage::disk('r2')->url($filename);
            return response()->json(['success' => true, 'url' => $url]);
        }

        return response()->json(['error' => 'Upload failed'], 500);
    }
}
```

```python
# r2_client.py
import boto3
from botocore.config import Config
import os

# Initialize R2 client
r2_client = boto3.client(
    's3',
    endpoint_url=f'https://{os.environ["R2_ACCOUNT_ID"]}.r2.cloudflarestorage.com',
    aws_access_key_id=os.environ['R2_ACCESS_KEY_ID'],
    aws_secret_access_key=os.environ['R2_SECRET_ACCESS_KEY'],
    config=Config(signature_version='s3v4'),
    region_name='auto'
)

def upload_file(file_obj, filename, content_type='application/octet-stream'):
    """
    Upload file to R2 bucket
    """
    try:
        r2_client.put_object(
            Bucket=os.environ['R2_BUCKET_NAME'],
            Key=f'uploads/{filename}',
            Body=file_obj,
            ContentType=content_type,
        )

        # Generate presigned URL
        presigned_url = r2_client.generate_presigned_url(
            'get_object',
            Params={
                'Bucket': os.environ['R2_BUCKET_NAME'],
                'Key': f'uploads/{filename}',
            },
            ExpiresIn=3600  # 1 hour
        )

        return presigned_url

    except Exception as e:
        print(f'Upload error: {e}')
        return None

# Flask route example
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/upload', methods=['POST'])
def upload():
    if 'file' not in request.files:
        return jsonify({'error': 'No file'}), 400

    file = request.files['file']
    filename = f'{request.form.get("user_id")}/{file.filename}'

    url = upload_file(file, filename, file.content_type)

    if url:
        return jsonify({'success': True, 'url': url})

    return jsonify({'error': 'Upload failed'}), 500
```

## Security Considerations

### 1. CORS Configuration

```javascript
// R2 CORS Policy
const corsConfig = {
  CORSRules: [
    {
      AllowedOrigins: ['https://mydomain.com'],
      AllowedMethods: ['GET', 'PUT', 'POST'],
      AllowedHeaders: ['Content-Type', 'Authorization'],
      ExposeHeaders: ['ETag'],
      MaxAgeSeconds: 3600,
    },
  ],
};

// Apply CORS via SDK
await r2.putBucketCors({
  Bucket: process.env.R2_BUCKET_NAME,
  CORSConfiguration: corsConfig,
});
```

### 2. Bucket Policies

```json
// Allow public read, deny all write except specific IAM
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadGetObject",
      "Effect": "Allow",
      "Principal": "*",
      "Action": ["s3:GetObject"],
      "Resource": `arn:aws:s3:::${process.env.R2_BUCKET_NAME}/*`
    }
  ]
}
```

### 3. Environment Variables

```bash
# ❌ Jangan hardcode credentials di code
```
