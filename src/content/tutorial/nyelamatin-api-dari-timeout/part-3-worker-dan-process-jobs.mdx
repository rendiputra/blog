Oke, lo udah punya:
- Redis connection
- Queue system
- API yang add jobs

Tapi ada yang missing | **Worker** yang actual process jobs.

Worker itu proses terpisah yang "listen" ke queue dan process setiap job yang masuk. Lo bisa jalanin multiple workers buat handle load.

Di part ini, gue bakal bikin worker yang real untuk:
- Email sending
- PDF generation
- Job event listeners
- Error handling
- Logging

## Apa Itu Worker?

Worker itu process yang独立的 dari API server:

```
┌─────────────────────────────────────────────────────────────┐
│                    API Server (Port 3000)                    │
│                                                              │
│  app.post('/register', async (req, res) => {                │
│    // Validate, create user                                  │
│    await addEmailJob({ to: email, otp }); // 50ms only     │
│    res.json({ success: true }); // Fast response!          │
│  });                                                         │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
                    ┌─────────────────┐
                    │  Job: email-otp │
                    │  Status: queued │
                    └─────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                    Worker Process (Port ?)                    │
│                                                              │
│  worker.process('email-send', async (job) => {              │
│    // Actual email sending (3 detik)                        │
│    await sendEmail(job.data);                               │
│    // Done! User dapet email di background                  │
│  });                                                         │
└─────────────────────────────────────────────────────────────┘
```

**Flow lengkap:**
1. User hit `/register`
2. API add job ke queue (50ms)
3. API response ke user (100ms total)
4. Worker pick up job dari queue
5. Worker process email (3 detik)
6. User dapet email tanpa harus nunggu

## Setup Worker

### Step 1: Create Worker File

```typescript
// workers/email.worker.ts
import { Worker, Job } from 'bullmq';
import Redis from 'ioredis';
import { EmailJobData } from '../types/email';

// Redis connection (sama kayak queue)
const connection = new Redis(process.env.REDIS_URL!, {
  maxRetriesPerRequest: null,
});

// Create worker
const emailWorker = new Worker(
  'email-send', // Queue name (harus sama kayak queue lu)
  async (job: Job<EmailJobData>) => {
    // Process job
    console.log(`Processing email job: ${job.id}`);
    console.log(`Template: ${job.data.template}`);
    console.log(`To: ${job.data.to}`);

    // Send email based on template
    switch (job.data.template) {
      case 'otp':
        return await sendOTPEmail(job.data);
      case 'welcome':
        return await sendWelcomeEmail(job.data);
      case 'password-reset':
        return await sendPasswordResetEmail(job.data);
      default:
        throw new Error(`Unknown template: ${job.data.template}`);
    }
  },
  {
    connection,
    concurrency: 5, // Process 5 jobs concurrently
  }
);

// Worker event listeners
emailWorker.on('completed', (job) => {
  console.log(`Job ${job.id} completed successfully`);
});

emailWorker.on('failed', (job, err) => {
  console.error(`Job ${job?.id} failed:`, err.message);
});

emailWorker.on('error', (err) => {
  console.error('Worker error:', err);
});

console.log('Email worker started!');
```

### Step 2: Implement Email Sending Functions

```typescript
// lib/email/sender.ts
import nodemailer from 'nodemailer';
import { EmailJobData } from '../../types/email';

// Setup transporter (sesuaikan dengan email provider lu)
const transporter = nodemailer.createTransport({
  host: process.env.SMTP_HOST,
  port: parseInt(process.env.SMTP_PORT || '587'),
  secure: false,
  auth: {
    user: process.env.SMTP_USER,
    pass: process.env.SMTP_PASS,
  },
});

export async function sendOTPEmail(data: EmailJobData) {
  const { to, data: templateData } = data;
  const { name, otp } = templateData;

  const html = `
    <h1>Verify Your Email</h1>
    <p>Hi ${name},</p>
    <p>Your verification code is:</p>
    <h2 style="font-size: 32px; letter-spacing: 8px;">${otp}</h2>
    <p>This code expires in 10 minutes.</p>
    <p>If you didn't request this, please ignore this email.</p>
  `;

  await transporter.sendMail({
    from: process.env.EMAIL_FROM,
    to,
    subject: 'Verify your email',
    html,
  });

  console.log(`OTP email sent to ${to}`);

  return { sent: true, to, template: 'otp' };
}

export async function sendWelcomeEmail(data: EmailJobData) {
  const { to, data: templateData } = data;
  const { name } = templateData;

  const html = `
    <h1>Welcome to Our App!</h1>
    <p>Hi ${name},</p>
    <p>Thank you for joining us. We're excited to have you!</p>
  `;

  await transporter.sendMail({
    from: process.env.EMAIL_FROM,
    to,
    subject: 'Welcome to Our App!',
    html,
  });

  return { sent: true, to, template: 'welcome' };
}

export async function sendPasswordResetEmail(data: EmailJobData) {
  const { to, data: templateData } = data;
  const { resetLink } = templateData;

  const html = `
    <h1>Password Reset</h1>
    <p>Click the link below to reset your password:</p>
    <a href="${resetLink}">Reset Password</a>
    <p>This link expires in 1 hour.</p>
  `;

  await transporter.sendMail({
    from: process.env.EMAIL_FROM,
    to,
    subject: 'Reset Your Password',
    html,
  });

  return { sent: true, to, template: 'password-reset' };
}
```

### Step 3: Run Worker

Lo bisa run worker sebagai:
- **Process terpisah** (recommended untuk production)
- **Part dari app yang sama** (oke untuk development)

```typescript
// workers/email.worker.ts | Updated with imports
import { Worker, Job } from 'bullmq';
import Redis from 'ioredis';
import { EmailJobData } from '../types/email';
import { sendOTPEmail, sendWelcomeEmail, sendPasswordResetEmail } from '../lib/email/sender';

const connection = new Redis(process.env.REDIS_URL!, {
  maxRetriesPerRequest: null,
});

const emailWorker = new Worker(
  'email-send',
  async (job: Job<EmailJobData>) => {
    console.log(`Processing: ${job.id} | Template: ${job.data.template}`);

    switch (job.data.template) {
      case 'otp':
        return await sendOTPEmail(job.data);
      case 'welcome':
        return await sendWelcomeEmail(job.data);
      case 'password-reset':
        return await sendPasswordResetEmail(job.data);
      default:
        throw new Error(`Unknown template: ${job.data.template}`);
    }
  },
  {
    connection,
    concurrency: 5,
  }
);

emailWorker.on('completed', (job) => {
  console.log(`Job ${job.id} completed`);
});

emailWorker.on('failed', (job, err) => {
  console.error(`Job ${job?.id} failed: ${err.message}`);
});

console.log('Email worker started');

// Graceful shutdown
process.on('SIGTERM', async () => {
  console.log('Shutting down worker...');
  await emailWorker.close();
  process.exit(0);
});
```

## PDF Generation Worker

Sekarang gue bikin worker yang lebih complex | PDF generation.

```typescript
// workers/pdf.worker.ts
import { Worker, Job } from 'bullmq';
import Redis from 'ioredis';
import PDFDocument from 'pdfkit';
import { S3Client, PutObjectCommand } from '@aws-sdk/client-s3';
import { getSignedUrl } from '@aws-sdk/s3-request-presigner';
import { PDFJobData } from '../lib/queue/pdf.queue';
import { Report } from '../models/report';

const connection = new Redis(process.env.REDIS_URL!, {
  maxRetriesPerRequest: null,
});

// S3 client (bisa pake R2 juga)
const s3 = new S3Client({
  region: process.env.AWS_REGION,
  credentials: {
    accessKeyId: process.env.AWS_ACCESS_KEY_ID!,
    secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY!,
  },
});

const pdfWorker = new Worker(
  'pdf-generation',
  async (job: Job<PDFJobData>) => {
    const { userId, reportType, dateRange, format } = job.data;

    console.log(`Generating ${reportType} report for user ${userId}`);

    // Update job progress
    await job.updateProgress(10);

    // Fetch data dari database
    const reportData = await fetchReportData(userId, reportType, dateRange);
    await job.updateProgress(30);

    // Generate PDF
    const pdfBuffer = await generatePDF(reportData, reportType);
    await job.updateProgress(70);

    // Upload ke S3/R2
    const key = `reports/${userId}/${Date.now()}-${reportType}.pdf`;
    await s3.send(new PutObjectCommand({
      Bucket: process.env.S3_BUCKET!,
      Key: key,
      Body: pdfBuffer,
      ContentType: 'application/pdf',
    }));

    // Generate signed URL (expires dalam 1 jam)
    const downloadUrl = await s3.send(new GetObjectCommand({
      Bucket: process.env.S3_BUCKET!,
      Key: key,
    }));

    const signedUrl = await getSignedUrl(s3, downloadUrl, { expiresIn: 3600 });

    await job.updateProgress(100);

    // Save to database
    const report = await Report.create({
      userId,
      type: reportType,
      fileUrl: signedUrl,
      generatedAt: new Date(),
    });

    return {
      success: true,
      reportId: report.id,
      downloadUrl: signedUrl,
    };
  },
  {
    connection,
    concurrency: 2, // PDF generation berat, lower concurrency
  }
);

async function fetchReportData(userId: string, type: string, dateRange: any) {
  // Fetch dari database
  // Implement sesuai kebutuhan
  return {
    userId,
    type,
    dateRange,
    // Data yang mau di-include di PDF
  };
}

async function generatePDF(data: any, type: string): Promise<Buffer> {
  return new Promise((resolve, reject) => {
    const doc = new PDFDocument();
    const chunks: Buffer[] = [];

    doc.on('data', (chunk) => chunks.push(chunk));
    doc.on('end', () => resolve(Buffer.concat(chunks)));
    doc.on('error', reject);

    // Header
    doc.fontSize(20).text(`${type.toUpperCase()} Report`, { align: 'center' });
    doc.moveDown();
    doc.fontSize(12).text(`Generated: ${new Date().toISOString()}`);
    doc.moveDown();

    // Content (sesuaikan dengan type)
    doc.fontSize(14).text('Summary', { underline: true });
    doc.fontSize(10).text(`Report Type: ${data.type}`);
    doc.text(`Date Range: ${data.dateRange.start} - ${data.dateRange.end}`);
    doc.moveDown();

    // Footer
    doc.moveDown(20);
    doc.fontSize(8).text('Generated by App', { align: 'center' });

    doc.end();
  });
}

pdfWorker.on('completed', (job, result) => {
```

## Error Handling Best Practices

### Retry Logic

```typescript
const worker = new Worker('email-send', async (job) => {
  try {
    // Process job
    await sendEmail(job.data);
    return { success: true };
  } catch (error: any) {
    // Check if retryable error
    if (error.code === 'ECONNREFUSED') {
      // Connection error | retry
      throw error; // BullMQ akan retry automatically
    }

    if (error.code === 'INVALID_EMAIL') {
      // Non-retryable error | don't throw
      return { success: false, reason: 'Invalid email address' };
    }

    // Unknown error | retry
    throw error;
  }
}, {
  connection,
  limiter: {
    max: 10,    // Max 10 jobs
    duration: 1000, // per 1 detik
  },
  backoff: {
    type: 'exponential',
    delay: 1000, // 1s, 2s, 4s, 8s...
  },
});
```

### Dead Letter Queue

Jobs yang gagal setelah semua retry attempts disebut "dead":

```typescript
// Setup dead letter queue
const deadLetterQueue = new Queue('dead-letter', { connection });

emailWorker.on('failed', async (job, err) => {
  if (job?.attemptsMade >= job.opts.attempts) {
    // Move to dead letter queue
    await deadLetterQueue.add('failed-email', {
      originalJob: job.data,
      error: err.message,
      failedAt: new Date(),
      attempts: job.attemptsMade,
    });

    console.log(`Job ${job.id} moved to dead letter queue`);
  }
});
```

## Graceful Shutdown

Worker harus handle shutdown dengan bener:

```typescript
// workers/email.worker.ts
async function shutdown() {
  console.log('Received shutdown signal...');

  // Stop accepting new jobs
  await emailWorker.close();

  // Wait untuk jobs yang sedang berjalan selesai (max 30 detik)
  const activeJobs = await emailWorker.getActiveJobs();

  if (activeJobs.length > 0) {
    console.log(`Waiting for ${activeJobs.length} active jobs to complete...`);

    await Promise.race([
      Promise.all(activeJobs.map(job => job.waitUntilFinished())),
      new Promise(resolve => setTimeout(resolve, 30000)) // Max 30s
    ]);
  }

  console.log('Worker shutdown complete');
  process.exit(0);
}

process.on('SIGTERM', shutdown);
process.on('SIGINT', shutdown);
```
